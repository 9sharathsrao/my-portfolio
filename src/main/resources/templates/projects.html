UNET-Based Terrain Classification

Our team and I developed a terrain classification system using PyTorch with a custom CNN/UNET model to accurately classify terrain images such as rocky, forest, and desert. The project involved data preprocessing, labeling, and augmentation to improve accuracy, along with GPU-accelerated training and deployment checkpoints for real-time inference. I also built an interactive Python application to test terrain images, showcasing AI integration in geospatial analysis and robotic navigation. This project highlights my expertise in deep learning workflows, model optimization, and image data pipelines.
