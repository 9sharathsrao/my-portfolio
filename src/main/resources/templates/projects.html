Projects

AppIdea: Social Idea-Sharing Platform

Developed a community-driven social platform using Flutter and Supabase, enabling users to seamlessly publish, discover, and interact with innovative concepts. I architected a complex relational database schema in Supabase utilizing foreign key constraints to track user interactions and content metadata across dedicated Ideas and Votes tables. To ensure data integrity and a smooth user experience, I implemented a robust Upvote/Downvote system with logic designed to prevent duplicate votes while providing real-time feedback on idea popularity.

To-Do Task Management App

Developed a cloud-enabled mobile application using Flutter that features a clean and intuitive UI for daily productivity management. I implemented a hybrid data strategy to ensure reliability and speed, using Sqflite for fast on-device storage and Firebase Firestore for real-time cloud synchronization across multiple devices. Secure user authentication was handled through Firebase Auth, ensuring that every user has a personalized and private task list.

VideoStream Explore

I built a dynamic video discovery platform using React and Tailwind CSS, focusing on delivering a responsive UI enhanced with custom Google Fonts and React Icons. By integrating the YouTube Data API v3 via Axios, I enabled the application to fetch real-time video feeds, channel metadata, and live search results. I managed the application's global state using Redux and handled client-side navigation between different content feeds and watch pages.
